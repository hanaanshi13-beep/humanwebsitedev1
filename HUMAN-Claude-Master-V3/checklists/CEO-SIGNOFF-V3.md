# HUMAN — CEO signoff checklist (V3)

Review **only real running website evidence**, not prompt promises. Use PASS / FAIL / BLOCKED and link to a screenshot or test.

- [ ] Hero: exact approved headline, brand status, live CTA; real desktop and mobile compositions; faces do not overlap words.
- [ ] Hero: user can choose story, jump to how HUMAN works, or visit waitlist; no forced storytelling.
- [ ] Eight scenes in locked order; no repeated transition line; real editable/accessible words.
- [ ] Motion: Reveal Lens, Clarity and Connected Thread implemented/simplified/rejected by quality evidence; no mandatory implementation of all candidate cues.
- [ ] Story is understandable with JS off / reduced motion / media blocked.
- [ ] Her and Him receive distinct equal-quality environments and truthful development wording.
- [ ] Actual app folder audited before any preview; real screenshots, illustrative labels, verified link; or an honest placeholder if missing.
- [ ] Waitlist five chapters, exactly three data-entry steps, validation, back/edit, optional updates not prechecked, no acceptance without real backend.
- [ ] About founder story verified or omitted; FAQ transparent about pricing, services, geography and launch status.
- [ ] Privacy, Terms and Disclaimer labelled pending review until approved; no real registration before legal/backend gate.
- [ ] No invented medical, clinical, testimonial, partner, subscriber, launch, pricing or availability claims.
- [ ] Playwright/screenshots 320/360/390/768/1024/1440/1920; browser/keyboard/reduced motion testing documented.
- [ ] No unapproved costs, leaked keys, real PII in logs/analytics, unlicensed images or live deployment.
- [ ] Site builds and works without Google Flow footage, with truthful posters and HTML interactions.
- [ ] Evidence: working preview, changed files, screenshots, build results, pending decisions, owner and next action.
